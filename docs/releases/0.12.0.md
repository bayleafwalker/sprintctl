# Sprintctl0.12.0

Adds durable accepted-effect discovery via `work.effect.list-accepted-v1`, requiring the separate `work.effect.list-accepted` capability. `work.effect.list-proposed` remains proposed-only and grants no accepted discovery authority. Both operations retain deterministic proposal creation order, bounded limits and repository isolation.

This additive API release keeps remote schema20 and requires no migration. Publish the immutable attested wheel from the reviewed merge tag; consumers must verify its release SHA256 before repinning. Code publication does not grant OAuth capabilities or deploy production runtimes.
