# Frozen cold-reader fixture protocol

Native bounded child: `sprintctl#2715`; broader `sprintctl#2661` and
`sprintctl#2663` qualification and their `agentops#2654` prerequisite remain open.

The population is nine independent fresh-agent attempts: three native
continuation before/after pairs (checkpoint repair, supplied comparison baseline,
and caller-reported access) and three native effect cases (matching receipt,
changed requested artifact, omitted receipt input). Each attempt has twelve
questions,108 questions total. Native IDs/timestamps are generated by the actual
owner; input hashes bind the exact resulting values. Case labels/answer values
are withheld from readers. Source locations are public evidence navigation,
not the hidden answer oracle.

Before dispatch, the coordinator freezes input, oracle, generator, grader,
prompt and protocol SHA256s in an append-only native decision event. No reader
starts before this freeze. Preparation failures before freeze are not reader
attempts; the first generator's nested observation lookup was repaired before
any reader existed. The failed preparation directory is retained separately.

Each reader starts with no inherited conversation and receives only one opaque
input-file path and the same frozen prompt. It may read that file once. Repository,
sibling/oracle, network/owner/tool work, reference execution and contact with
other readers are prohibited. This is instructed isolation, not an OS sandbox
or proof of inaccessible files. Tool-call transcripts are retained/audited when
available; otherwise actual tool-call count/compliance remain explicitly unknown.
No assumed zero or one is substituted for unaudited measurement.

Answers must be exactly `{"answers": {question_id: {"value": VALUE,
"sources": [JSON_POINTER]}}}`. The expected value/type and acceptable source
locations are frozen. Every supplied citation must exist and be an allowed
location; one correct citation cannot hide a fabricated extra citation. Factual
correctness and citation validity are also retained separately. Unknown cannot
replace an available known answer. Correct unknowns are counted separately from
known facts. Extra question answers are retained as unsupported incorrect claims,
in addition to the fixed question denominator. Missing answers are unanswered.
Malformed output fails the attempt and leaves all twelve questions unanswered.

Timeout is600seconds from requested dispatch to observed final completion. The
coordinator records UTC start/end; elapsed wall time includes inseparable queue,
orchestration and observation delay. It is not cognitive effort, active working
time or time saved. Exact model revision, cost and unaudited calls remain null
when unavailable. Harness is the observed fresh Codex collaboration session.
No alternate provider or host is implied.

All nine assigned attempts remain in the denominator, including timeouts,
malformed output and failed instruction compliance. No favorable rerun replaces
a result; any extra attempt needs a new ID and separate report. A parent review
may discover ambiguity in a question, but it is reported as a limitation rather
than changing the frozen oracle after dispatch.

Paired accuracy, elapsed wall time and any measured calls are reported
**descriptively**, including unchanged or worse results. No representative human
effort, causal improvement, provider superiority, production portability or
complete result transfer is established. Broad blocked qualification is not
accepted by completing this bounded fixture experiment.
